Tentang data ini

Grafik kosong karena robot belum terhubung. Tidak ada data live atau rekaman yang ditampilkan.

  • Garis putus = setpoint, garis teal = nilai terukur sensor.
  • Rekam menyimpan setiap sampel yang masuk sampai dihentikan; Export CSV tanpa rekaman mengambil isi jendela grafik.
  • Kolom CSV: waktu (ms), setpoint, ball position, error, output (%), status.
  • Untuk data 100 Hz langsung dari slave, pakai rekam_data.py lewat USB.

Hubungkan server dan robot di Settings untuk menerima telemetri.
